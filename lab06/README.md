### Задание 1 **(3)**
*Рассмотрим следующую программу на С++.*
```
#include <iostream>
#include <cmath>
int main() {
   double x = 0;
   const auto Pi = std::acos(0) * 2;
   std::cout << Pi << std::endl;
   return 0;
}
```
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

## Ответ 

- const = значение нельзя менять во время работы программы. Оно посчитаться прямо при запуске.
- constexpr = значение обязано посчитаться компилятором еще до запуска программы.

### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

## Ответ 

В первой части программы создаются переменные x и y типа int. Во второй части — тоже x и y типа double. В C++ нельзя объявить две переменные с одним и тем же именем в одном и том же месте. Фигурные скобки создают отдельные локальные зоны. Они работают как границы. Программа заходит в первый блок { }, создает там int x и int y. При выходе из этого блока переменные x и y удаляются из памяти. Программа заходит во второй блок { }. Переменные x и y были удалены поэтому можно спокойно создать новые переменные с такими же именами, но уже типа double. Если убрать фигурные скобки обе части кода окажутся внутри main. Программа попытается создать int x, а потом сразу же еще раз создать double x. Компилятор выдаст ошибку: «Повторное объявление переменной x».

### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

## Ответ 

В коде есть две разные i. Одна главная, другая внутренняя. Они не мешают друг другу.

Внутренний цикл

- Внутри крутится своя, внутренняя i она меняется от 0 до 2.
- Она прибавляет к s числа: 0 + 1 + 2 = 3.
- Внешний цикл заставляет её повториться 4 раза.
- Значит, внутренний цикл прибавит к s ровно: 3 * 4 = 12.

После внутреннего цикла

- Когда внутренний цикл заканчивается, внутренняя i исчезает. Программа снова видит внешнюю i.
- Внешняя i за 4 прохода меняется от 0 до 3.
- Эта строка прибавляет к s по очереди эти числа: 0 + 1 + 2 + 3 = 6.

Внутренний цикл накопил 12. Строка после него накопила 6. 12 + 6 = 18

### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

## Ответ

В Python нет отдельной переменной для вложенного цикла. Переменная i здесь одна на всё.

i по очереди становится 0, 1 и 2. К s прибавляется 0 + 1 + 2 = 3. (s += i): Вложенный цикл закончился, но переменная i не удаляется. Она осталась равна последнему значению — 2. Поэтому к s прибавляется еще 2.
Итог за один проход: 3 + 2 = 5. Так как внешний цикл повторяется 4 раза, общая сумма будет: 5 * 4 = 20.

В C++ переменная в заголовке цикла (int i) создается заново. Она существует только внутри цикла и «умирает» после его завершения. Внешняя i остается нетронутой. В Python цикл не создает новую переменную, а просто перезаписывает существующую. После завершения вложенного цикла i не исчезает, а остается с последним значением (2).

### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?

## Ответ

Функция id() возвращает уникальный идентификатор объекта в памяти. При a = 'Hello world' создается строка, а после b = a обе переменные ссылаются на один и тот же объект (поэтому первые два id совпадают). Так как строки в Python неизменяемы, операция a += ' and goodbye' создает новую строку, и переменная a переключается на неё (её id меняется). Переменная b при этом продолжает указывать на исходную строку. Поэтому в конце содержимое и id различаются. Строки создавались дважды: при первом присваивании и в момент выполнения +=.
