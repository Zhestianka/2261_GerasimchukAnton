### Задание 6 **(2)**

*Для какого минимального значения* $n$ *программа на С++ выведет* **inf**? *Объясните
ответ.* *Что произойдет, если тип* **double** *заменить на* **long double**?
```
int n=...;
double s = pow(2, n);
std::cout << std::fixed << s << std::endl;
```

## Задание 6

Double занимает 64 бита: 1 бит знака, 11 бит порядка и 52 бита мантиссы. Порядок хранится со смещением 1023. Комбинация из 11 единиц (2047) зарезервирована для inf, поэтому максимальный допустимый порядок — 2046. Тогда максимальная степень двойки n = 2046 − 1023 = 1023 При n = 1024 порядок становится равным 2047, что даёт inf.

long double может иметь больший диапазон, но это зависит от компилятора и платформы. Например, в распространённой реализации с расширенным 80-битным форматом диапазон порядка 10⁴⁹³², поэтому 2¹⁰²⁴ ещё будет конечным. На некоторых платформах long double совпадает по диапазону с double, и результат не изменится.

*Какое минимальное натуральное число при преобразовании в тип* **double** *записывается с погрешностью? Объясните
ответ. Почему следующее за ним число уже выводится без погрешности?*

## Задание 8

Минимальное натуральное число, которое нельзя точно представить в double, — 2 в 53 степени + 1 = 9007199254740993. В double точность — 53 значащих двоичных разряда. Поэтому все целые до 2 в 53 степени представимы точно. После 2 в 53 степени шаг между соседними представимыми числами становится равен 2

число находится 2 в 53 степени + 1 = 9007199254740993 нечётное и находится между 9007199254740992 и 9007199254740994. Оно округляется к 9007199254740992, поэтому записывается с погрешностью. Следуйщее число 9007199254740994 = 2 в пятой степени + 2 чётное и совпадает с одним из представимых чисел, поэтому выводится точно.
