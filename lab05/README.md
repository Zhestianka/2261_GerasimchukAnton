## Задание 1

Возьмём числа 3/32 и 1/10.

**1. Число 3/32.** Знаменатель 32 = 2 в 5 - ой степени. Это степень двойки, поэтому двоичная запись будет конечной. Умножаем дробную часть на 2 и каждый раз выписываем целую часть:

| Действие| Целая часть | бит |
|---:|---:|---:|
| 3/32 * 2 =  3/16| 0 | 0 |
| 3/16 * 2 = 3/8 | 0 | 0 |
| 3/8 * 2 = 3/4 | 0 | 0 |
| 3/4 * 2 = 3/2 = 1,5 | 1 | 1 |
| 0,5 * 2 = 1,0 | 1 | 1 |

Получаем: **3/32 = 0,00011₂**.

**2. Число 1/10.** Знаменатель 10 не является степенью двойки, поэтому запись будет бесконечной. Умножаем дробную часть на 2

| Дробная часть до умножения | Удвоенная часть | Следующий бит |
|---:|---:|---:|
| 0,1 | 0,2 | 0 |
| 0,2 | 0,4 | 0 |
| 0,4 | 0,8 | 0 |
| 0,8 | 1,6 | 1 |
| 0,6 | 1,2 | 1 |
| 0,2 | 0,4 | 0 |
| 0,4 | 0,8 | 0 |
| 0,8 | 1,6 | 1 |
| 0,6 | 1,2 | 1 |
| 0,2 | 0,4 | 0 |
| 0,4 | 0,8 | 0 |
| 0,8 | 1,6 | 1 |


После появления остатка 0,2 процесс повторяется. Ответ: 0,0001(1001).

Здесь `1001` — период, а `0001` — непериодическая часть.
